# DEVLOG
This document serves as a developer logging book to store software and architectural changes

Template:

```
1. Log Title
2. Log Date
3. Log Brief Description
4. Log Affected Variables in the Software 
5. Log Extended Description
```
Example:
<br>
```
LOG -
Title: Transport Mechanism Migration
When: 01/01/2000
Brief: Migrated network protocol logic and code from nodeJS to Go Lang, ensuring less overhead
Affected: Node JS server file, Client-side Interfaces and Scripts
Extended: NodeJS has more overhead compared to Go Lang and the project itself needs efficientt data transportation, hence
Go Lang was chosen as it compiles down to binary.
```
